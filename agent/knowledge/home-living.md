# 家居生活：家饰 / 家具 / 灯具 / 布艺软装选购口径

本商城家居类目以「布艺软装（39 款）、床品件套（37 款）、被枕（22 款）、家饰（15 款）、家具（14 款）、夏凉（12 款）、灯具（3 款）」为主，价格从几元的收纳小件到数千元的家具，中位数约 168 元。

## 怎么挑

- **先定场景再定材质**：床品看面料（纯棉 / 水洗棉 / 桑蚕丝 / 澳洲羊毛）与季节（夏凉 vs 秋冬保暖）；家饰看摆放空间尺寸与色系；灯具看色温与照明面积。
- **件套类注意"件套"含义**：四件套通常指被套、床单、两只枕套，不含被芯与枕芯。买家说"买一套能直接睡"时要主动提示需另配被芯。
- **尺寸优先于花色**：床品按 1.2m / 1.5m / 1.8m 床区分，尺寸不符是最常见退货原因。
- **家具与灯具**单价高，建议引导买家看清商品详情里的尺寸图与安装说明。

## 价格区间参考（本商城在售商品）

- 小件收纳 / 毛巾 / 文具：5 ~ 60 元
- 枕芯、夏凉被、普通四件套：60 ~ 300 元
- 中高端四件套、羊毛被、蚕丝被：300 ~ 900 元
- 大件家具、高端床品：900 ~ 4200 元

## 避坑点

- "纯棉"不等于"长绒棉"，"桑蚕丝"要看含量标注，别把"丝滑感"当真丝。
- 划线价（counter_price）是专柜价，真实售价看 retail_price。
- 布艺商品存在批次色差，深色与浅色尽量一次买齐。
- 本商城不涉及跨境运费、关税与到手价，标价即商品售价；运费与优惠以结算页为准。
