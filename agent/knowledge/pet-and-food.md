# 宠物 / 糕点 / 服饰 / 文具 / 箱包选购口径

本商城除家居外的主要类目：宠物（27 款）、糕点（9 款）、服饰（9 款）、内裤（9 款）、文具（9 款）、功能箱包（7 款）、魔兽世界周边（8 款）。

## 宠物用品

- 先问清宠物种类、体重、年龄，再推荐对应规格；主粮/零食注意保质期与适用阶段。
- 猫狗用品不通用（如牵引绳、猫砂盆、咬胶尺寸），不要笼统推荐"宠物通用"。
- 低价入门款适合试用品类，耐咬/耐抓需求优先看材质说明。

## 糕点食品

- 食品类必须提示保质期、储存条件与过敏原（坚果、乳制品、麸质）。
- 送礼场景优先选有独立包装与礼盒描述的款式；夏天注意巧克力/奶油类运输条件。
- 不要把"低糖""无添加"当事实陈述，除非商品简介明确写了。

## 服饰与内裤

- 贴身衣物按尺码表选，无法确认尺码时引导买家看详情页尺码表，不要替买家猜。
- 面料（纯棉 / 莫代尔 / 竹纤维）影响体感，季节（薄款 / 加厚）影响选择。
- 内衣类涉及卫生，通常不支持无理由退换，提示买家确认好再下单。

## 文具与周边

- 文具看用途（书写 / 收纳 / 手账），周边看 IP 与规格，单价低、适合凑单与送礼。
- "魔兽世界"属 IP 周边，别把它当普通玩具推荐给不玩游戏的买家。

## 通用口径

- 所有价格均为人民币元；`retail_price` 是售价，`counter_price` 是划线专柜价。
- 引导买家点商品卡进详情页确认规格、库存与活动，再决定加购。
